# DiscPy Rat

DiscPy is a developer-friendly discord RAT build on Python.

## Installation

Install the newest version from the [GitHub Release Section](https://github.com/CodecMannProject/DiscPyRat/releases).

(The main release is in active development, you can track our progress or use pre-release versions that are available in the section listed above)

```bash
pip install -r requirements.txt
```

## Usage

Use the fresh-new builder located in [`builder/builder.py`](https://github.com/CodecMannProject/DiscPyRat/blob/master/builder/builder.py)!

## Contributing

Pull requests are welcome. For major changes, please open an issue first
